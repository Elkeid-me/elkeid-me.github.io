## 一通电话

写这篇文章源于两件事。一是刘胜与老师的两篇文章——《我不得不把才华埋葬在昨天》和《2025年终总结特别篇：我为什么不读博》。

二是字节跳动Seed Infra团队打来电话，问我考虑不考虑实习。很遗憾，我所在的实验室，不放学生实习。

## 两种时间

M实验室隶属于北京大学，管理模式相当老派：所谓的“集体领导”，实则凡事由老大一人独断。每日早打卡晚签到，学生完全无法外出实习——甚至被要求签署不实习的保证书。没有老大分配任务，大家不会也不敢主动做事。开学一周了，什么都没有发生，只是日复一日地通勤。在国家和学院之外给的额外劳务补助，也是零。

> 可能有人要说，国家和学院都给你补助了，为什么还要实验室和导师给。但国家和学院的补助几乎是无条件的——学生哪怕不去实验室、天天在外面实习，也照样能发。天天通勤早打卡晚签到，额外补贴一分没有，那就纯粹是不近人情了。
>
> 我建议老大哪怕学学资本主义呢：发钱还是能激励人的。现在把“实验室是你家"、"我们是一家人”挂嘴边，纯粹的封建大家长制。

一边是天天通勤却无事可做；另一边是业界在发生翻天覆地的变化，而我只能望洋兴叹——Seed Infra给我打了电话，如果我是自由身，至少能试一试；但现在连试的机会都没有。

想想颇为荒诞。在这种局面下，老大还只会建议我们用豆包。

3月的时候我感觉风向不对。一方面是业界开始大举推进Harness工程；另一方面是考研复试期间，M实验室四处联系考生邀请参观。结果：一些联系其他实验室的考生，也来M实验室参观了。M实验室和那边说“他联系的是我们”，那边的老师转头就把名额给了别人。部分学生得知M实验室的管理水平后，直接选择二战。

这意味着什么？实验室在大量招生，满足出书的项目需求，大概率研二研三都没有机会去实习。

所以我3月份开始找实习。倒真找到了，在飞书PC客户端组写C++，接触了公司的产品。可惜Seed的电话是9月来的，终究只是一个未兑现的可能性。

## 字节的速度

在飞书实习的这段时间，我第一次近距离感受到了字节的速度。不是那种“我们有很多资源所以可以铺很多方向”的速度，而是**方向本身在以月为单位刷新**的速度。

就拿AI产品线来说。字节的Coding Agent TRAE早就有了（前身MarsCode，2024年），接着是TRAE的Solo模式，再接着TRAE Solo独立，后来又改名TRAE Work——明牌是类WorkBuddy的工作Agent，不是，或不只是Coding。字节还有海外市场的AnyGen，以及豆包系的企业版和办公产品。这都是今年上半年搞出来的东西。至于什么BUA、CUA[^1]，都是我以前从未见过但在公司实实在在用到的产品。

内部对AI的使用更令我震撼。不限量的GPT、内部版本的CLI Agent；甚至飞书知识问答都让我大吃一惊。尽管豆包被调侃为“糖包”，但同样基于Seed基座模型的飞书知识问答确实相当强。

我开始想一个问题：**读研是不是错误的选择？**如果带着现在的记忆回到两年前，我大概会四处找实习然后本科毕业工作。

## 时间线

但如果不带着记忆回去呢？那时候的我不会觉得AI发展这么快。我来拉一条时间线，看看这两年发生了什么：

| 时间         | 事件                                                     |
| ------------ | -------------------------------------------------------- |
| 2024上半年   | 聊天框为主流交互形态                                     |
| 2024上半年   | 我还在说“什么代码都用AI只会害了大家”                     |
| 2025年1月    | DeepSeek发布R1及开源权重、相关论文；“思考”后输出成为标配 |
| 2025年上半年 | 我的毕业设计还是手写代码                                 |
| 2025年中     | Coding Agent开始起飞（虽然Cursor出现的更早）             |
| 2026年1月    | OpenClaw大火；非Coding Agent开始普及                     |
| 2026上半年   | 我在字节实习，开始大量Vibe Coding                        |
| 2026年7月    | Codex与ChatGPT App合并；Coding/非Coding Agent界限模糊    |
| 2026年9月    | GPT-6 Astra发布                                          |

去年上半年还以聊天框为主，功能强大的Agent在年中才兴起，而面向非程序员的非Coding Agent甚至要等到今年年初。Coding和非Coding Agent的界限逐渐模糊，用户群体日益扩张。直到GPT-6 Astra，核弹瘫坐。

一年前的“正常”和今天的“正常”之间，隔着一场革命。而这场革命发生的时候，我正坐在没有任务的实验室里通勤。

## 不想读博

所以我也不想读博。

M实验室的方向本来就是工业界 $>$ 学术界，甚至我们还在用学术界六年前的课题。AI的加速式发展让我很难想象博士毕业会发生什么。毕业即失业吗？

## 助教手记

正好我这学期当助教。第一节上机课，很多同学电脑用得不是很顺畅，但已经熟练驾驭豆包、DeepSeek甚至GPT来写代码——机房不方便登录，大家还是以手机聊天框为主。

这好吗？

我看挺好的。

助教在答疑时直接让学生问AI，在一年前可能是最不负责的做法，但在今天可能是最负责的做法。因为AI能给出的代码解释和调试建议，已经超过了大部分助教的能力范围（包括我）。与其让学生排长队等一个不一定能解答的助教，不如让他们直接和一个 $7\times24$ 小时在线、永远耐心的AI对话。

这让我想起2024年的自己，“什么代码都用AI只会害了大家”。那时候我觉得手写代码是正道，用AI是偷懒。现在看来，这种想法本身就是一种时间错位。就像坚持用毛笔写信的人嘲笑用电子邮件的人：毛笔自然是一种艺术，但代表不了今天的生产力。世界已经不是那个世界了。

## 一个递归

其实这篇文章也是AI写的。我就写了点提纲和背景。

一个读研期间没学到什么技术的人，在AI公司实习后用AI写了一篇关于AI如何改变一切的文章。这本身就是一个关于加速的故事——两年前我不会写这样的文章，不是因为没有能力，而是因为不存在这样的工具和这样的经历。

2024年我不会想到自己会去字节实习。2025年我不会想到自己会大量Vibe Coding。2026年我不会想到AI可以帮我把提纲变成一篇完整的文章。

每一个“不会想到”之间的间隔，正在缩短。

## 结语

我没有答案。读研是对是错？进实验室是弯路还是必经之路？AI会淘汰多少人、创造多少机会？这些问题在2024年有标准答案，在2025年标准答案开始动摇，到2026年标准答案本身已经不复存在。

我能确定的只有一件事：世界在加速，而很多地方还在以静止的速度运转。这中间的落差，最终会由身处其中的人来承担。

那通来自Seed Infra的电话，我没有接到该接的地方。但至少，我看见了加速是什么样子。
